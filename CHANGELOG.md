# Changelog

Notable project changes are recorded here.

## [0.2.0] - 2026-10-12

### Added

- Added a VS Code extension for checking accessibility issues while editing.

## [0.1.0] - 2026-10-03

### Added

- Responsive React + TypeScript landing page based on the Accessibul11y design system.
- Section navigation, palette and typography specimens, and scan-result preview.
- Initial accessibility affordances: semantic landmarks, skip link, visible keyboard focus, descriptive image text, and reduced-motion support.
